# 阶段 6：主程序整合实现记录

> 对应原始规划中的「阶段 6：主程序整合 main.py」。

## 本阶段目标

- 将 scanner / parser / matcher / notifier 稳定串联到主流程。
- 提供长跑模式与单次执行模式，便于 cron 与手工测试。
- 增强日志可观测性与异常隔离。

## 已实现内容

1. 增加统一日志初始化：`setup_logging()`。
2. 保持 `run_once()` 作为核心单轮函数，并返回处理数量便于测试。
3. 增加 `run_loop()` 长跑入口。
4. 增加 CLI 参数：
   - `--once`：只执行一轮
   - `--log-level`：控制日志级别
5. 保留逐条公告异常隔离与逐条 history 持久化策略。
6. 新增 `tests/test_main_core.py` 覆盖关键主流程行为。

## 下一步（阶段 7）

  - 增加组件间集成测试（mock 网络）
  - 增加错误注入场景
  - 验证长跑稳定性（多轮模拟）
