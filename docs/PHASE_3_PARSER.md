# 阶段 3：公告解析模块实现记录

> 对应原始规划中的「阶段 3：实现公告解析模块 parser.py」。

## 本阶段目标

- 从公告标题和正文提取下架币种列表。
- 提升解析结果可用性，减少常见误识别。

## 已实现内容

1. 抽离 `extract_symbols_from_text(text)`，统一标题/正文解析逻辑。
2. 支持交易对模式识别（`ABC/USDT`、`ABC_USDT`）并提取基础币。
3. 增加停用词集合（公告常见功能词）与归一化过滤，减少噪声。
4. 详情页抓取逻辑独立为 `_fetch_announcement_text(url)`，主流程更清晰。
5. 添加解析核心单元测试 `tests/test_parser_core.py`。

## 设计说明

- 当前采用“规则+正则”解析，优点是简单稳定、易维护。
- 下一阶段可引入“交易所可交易币种白名单”做二次过滤，进一步降低误报。

## 下一步（阶段 4）

- 强化持仓获取策略（API + 本地 watchlist 双通道可观测性）。
- 为 matcher 增加更多错误分级与测试覆盖。
